
## Описание
Программа на Python, которая моделирует банковскую систему. 
Реализованы счета разных типов, история операций, обработка исключений, а также сохранение и загрузка данных в JSON и XML.

## Что реализовано
- ООП: наследование (от базового класса Account созданы 3 наследника), полиморфизм (переопределение метода withdraw).
- Исключения: собственное исключение NoMoneyError и обработка встроенных (ValueError, LookupError).
- CRUD: добавление, поиск, изменение баланса и удаление счетов.
- Форматы данных: сохранение и чтение из файлов .json и .xml.

## Классы
- Account — базовый счет (номер, баланс).
- SavingsAccount — сберегательный (с процентами).
- CheckingAccount — текущий (с овердрафтом).
- CreditAccount — кредитный (с кредитным лимитом).
- Client — клиент банка.
- Transaction — запись об операции.
- Bank — управляет счетами и сохранением файлов.

## Как запустить
1. Скачать файл bank.py.
2. Запустить через терминал или PyCharm:
   python bank.py
